# School Administration System Conventions
- Implement modular services for Principal, Teacher, Parent, and Student roles.
- Enforce Role-Based Access Control (RBAC) and clean schema boundaries.
- Output deterministic, complete, and production-ready code.
- No conversational filler, pleasantries, or placeholders (e.g., avoid `// TODO` or `pass`).
- Implement proper error handling, data models, and HTTP status codes.
