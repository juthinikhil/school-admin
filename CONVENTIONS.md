# School Administration System Conventions
- Target Stack: Node.js (Express), PostgreSQL (pg), Redis, Docker.
- Enforce Role-Based Access Control (RBAC): Principal, Teacher, Parent, Student.
- Output deterministic, complete, and production-ready source code.
- No conversational filler, pleasantries, or placeholders (avoid '// TODO' or 'pass').
- Implement proper error handling, typed routes, and standard HTTP status codes.
